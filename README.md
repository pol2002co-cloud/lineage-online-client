# 온라인 멀티플레이 접속 전용 클라이언트

공개 풀버전 게시가 완료되었습니다. GitHub 로그인 없이 다운로드할 수 있습니다.

**[최신 풀버전 다운로드](https://github.com/pol2002co-cloud/lineage-online-client/releases/latest)** · [ZIP 직접 다운로드](https://github.com/pol2002co-cloud/lineage-online-client/releases/download/v2026.10.26/Lineage-Online-Client-2026.10.26.zip)

1. 릴리스의 `Lineage-Online-Client-2026.10.26.zip`을 다운로드합니다.
2. ZIP 전체 압축을 풉니다.
3. `게임실행.exe` → **플레이**를 누르고 본인의 게임 계정으로 접속합니다.

참가자는 Tailscale 설치·로그인·공유 초대나 서버 주소 설정이 필요 없습니다. 런처의 **업데이트 확인**, **패치 받기 / 복구**로 서버가 제공하는 서명된 클라이언트 패치를 받을 수 있습니다. 게임 서버가 켜져 있어야 접속할 수 있습니다.

이 저장소는 접속 전용 배포 페이지입니다. 서버 실행 파일·서버 소스·DB·계정·캐릭터·개인 저장 파일·서명 개인키는 배포하지 않습니다. 기존 비공개 저장소와 별도로 운영됩니다.

2026-10-26 배포: 공개 배포 링크를 적용한 런처와 기존 최신 클라이언트 자산을 포함합니다. 최신 마법 이펙트 호환 수정은 서버에 적용되어 접속 시 사용됩니다.

ZIP 파일과 함께 제공하는 `.sha256`으로 파일 무결성을 확인할 수 있습니다. GitHub의 자동 생성 `Source code` ZIP은 게임 클라이언트가 아닙니다.
